火災保険の見直し、更新前に確認すること
賃貸と持ち家で見る項目が違う

家計の保健室 編集部　/ 公開日 2026年11月5日　/ 最終更新日 2026年11月5日
情報源：日本損害保険協会・財務省・国土交通省の公表情報（2026年11月5日確認）／補償・条件・手続きは保険会社ごとに異なります　/　編集方針

更新の案内が届いたら、見積もりを取る前に、 いまの契約が何を、いくらまで、どこまで補償しているかを保険証券から書き出します。 賃貸なら家財と賠償、持ち家なら建物と家財と、見る項目が変わります。 ここでは、書き出す項目、賃貸と持ち家の違い、水災補償の考え方、同じ条件で比べる方法を順に整理します。 特定の会社や商品は勧めません。

この記事で分かること

  • 保険証券から、更新前に書き出しておく項目
  • 賃貸と持ち家で、見る項目がどう違うか
  • 水災補償を付けるかを、ハザードマップを見て考える手順と、同じ条件で見積もりを比べる方法

保険料の安さだけで決めず、いまの条件を書き出し、賃貸か持ち家かで見る項目を分け、同じ条件で比べるのが基本です。

この記事で書かないこと

保険料の金額、保険金額の相場、割引率は書きません。会社・商品・建物・所在地で変わるためです。 どの会社・どの商品がよいか、順位や推奨も出しません。 水災補償を付けるべきかどうかも、このページでは決めません。 公式に確認できた範囲の説明と、確認のしかたまでを書き、 支払い条件や保険金額の決め方は、契約中の保険会社・代理店に確認する前提にしています。

手順1：更新案内と保険証券を手元に出す

届いた更新案内（満期のお知らせ）と、保険証券（または契約内容の確認画面）を並べます。 様式は会社ごとに違うため、項目の名前が少し違っても、次の手順2の内容を探せば足ります。

保険証券の一般的な読み方は、保険証券のどこを見る？にまとめています。 この記事では火災保険に絞って、更新前に特に見る項目を挙げます。

手順2：現在の条件を書き出す

次の項目を、メモや表に写します。意味が分からない項目は、推測で書かず、そのまま写して契約中の保険会社・代理店に聞きます。

保険の対象：建物と家財は分けて契約する

日本損害保険協会は、火災保険では建物と家財を分けて契約することになっていると説明しています。 建物は契約したが家財は契約しなかった、ということがないよう注意を呼びかけ、 借家にお住まいの方は家財のみ契約することになるとしています。 また、家財を契約するとき、高額な貴金属や美術品などは保険会社に知らせないと保険金が支払われない場合がある、とも書かれています。

保険金額：再調達価額か、時価か

同じページによると、火災保険の契約金額の設定方法には、「再調達価額」（同等のものを新たに建築・購入するのに必要な金額）をもとにする方法と、 「時価」（再調達価額から、年月の経過や使用による消耗分を差し引いた金額）をもとにする方法があります。 時価で契約するときは、契約金額を時価いっぱいに設定しておくことが基本で、 時価を下回って契約した場合は、損害額の全額が補償されない場合があると説明されています。 証券の保険金額がどちらの基準で決まっているかが分からないときは、そのまま写して保険会社・代理店に確認します。

補償範囲：「火災保険」の中身は商品で違う

日本損害保険協会は、火災保険を、住宅を取り巻くさまざまなリスクを総合的に補償するタイプ（住宅総合保険）と、 ベーシックな補償のタイプ（住宅火災保険）に大きく分かれるとしています。 同協会の補償内容の一覧では、火災・落雷・破裂爆発・風災・ひょう災・雪災はどちらのタイプでも「○」ですが、 水災、自動車の飛込み等による飛来・落下・衝突、給排水設備の事故等による水濡れ、騒じょう等による暴行・破壊、盗難は、住宅総合保険が「○」、住宅火災保険は「×」です。 ただし、同協会のQ&Aには「保険会社によって補償内容は異なっていますので、詳細については保険会社または代理店に確認することが必要」とあります。 タイプ名だけで判断せず、証券で一つずつ付いているかを確認します。

風災・ひょう災・雪災と、住宅総合保険の水災には、「一部自己負担額がある場合もあります」と注記されています。 証券に自己負担額（免責）の欄があれば、金額を写しておきます。

地震保険：火災保険では地震の損害は補償されない

日本損害保険協会は、地震・噴火・津波による損害は、すまいの保険（火災保険）では補償されず、地震保険で補償されると説明しています。 財務省も、火災保険では地震を原因とする火災による損害や、地震により延焼・拡大した損害は補償されないとしています。 地震保険は火災保険に付帯する方式で、火災保険への加入が前提です。すでに火災保険を契約している場合は、 契約期間の途中からでも地震保険に加入できるとされています。

地震保険の対象は居住用の建物と家財です。保険金額は火災保険の保険金額の30％～50％の範囲内で決め、 限度額は建物5,000万円、家財1,000万円です（財務省、日本損害保険協会）。 保険期間は短期（1年）と長期（2年～5年）があり、保険料は建物の構造と所在地により異なります（財務省）。 証券では、地震保険が付いているか、付いているなら建物・家財それぞれの金額と期間を写します。

手順3：賃貸と持ち家で、見る項目を分ける

賃貸：家財と、賠償の備えを見る

日本損害保険協会のQ&Aによると、賃貸住宅では建物は家主の所有で、家主が建物と家財に火災保険を契約していることが考えられても、 その保険で補償されるのは家主自身の所有物で、入居者の家財は補償されません。 入居者が家財の損害に備えるには、自分で家財に対する火災保険を契約する必要があります。

さらに同ページは、失火によって借りている部屋を焼失させた場合、入居者は家主に対して債務不履行に基づく損害賠償責任を負い、 これは失火責任法の適用を受けないため、備えるには家財の火災保険に特約として借家人賠償責任保険（補償特約）を付帯する必要があるとしています。 この特約は、借家人の責任による火災、破裂・爆発などで借りた部屋に損害を与え、家主に対して賠償責任を負ったときの損害を補償するものです。

一方、ガス爆発などで近隣の建物にも被害が出た場合や、水漏れで階下の住民の家財に損害を与えた場合は、借家人賠償責任保険では補償されません。 これらに備えるのが個人賠償責任保険（補償特約）で、借りた部屋に対する賠償責任は補償されません。 そのため、賃貸住宅では「借家人賠償責任保険（補償特約）」と「個人賠償責任保険（補償特約）」の2つがあった方が安心とされています。 個人賠償責任保険は、火災保険のほか自動車保険や傷害保険などの特約として契約でき、家族が起こした事故も対象になると説明されています。 すでに別の保険で付けていないかも、証券で確認します。

賃貸で更新前に写す項目をまとめると、次のとおりです。

  • 家財の保険金額（建物の欄はない、または家主の契約）
  • 借家人賠償責任の特約の有無
  • 個人賠償責任の特約の有無（自動車保険・傷害保険など、ほかの契約で付いていないか）
  • 水災・盗難・水濡れなどが付いているか
  • 地震保険（家財）が付いているか

持ち家：建物と家財、両方の金額を見る

持ち家では、建物と家財を分けて契約します。建物の保険金額と家財の保険金額を別々に写し、 それぞれが再調達価額と時価のどちらを基準にしているかを確認します（手順2）。 地震保険は建物・家財のそれぞれに付けられるため、どちらに付いているかも見ます。 日本損害保険協会は、自己所有の住宅でも、ガス爆発などの事故に備えるには個人賠償責任保険（補償特約）の加入が必要だとしています。

なお、日本損害保険協会は、隣家から出た火災で自宅が焼失した場合でも、失火原因が隣家の「重大な過失」である場合を除き損害賠償請求はできないため、 自分の家からの出火だけでなく隣家からの延焼に備える意味でも、各自が火災保険を契約しておくことが必要だと説明しています。

マンションの区分所有や、住宅ローンに伴う火災保険の契約条件は、この記事では扱いません。 建物の管理規約や金融機関の案内に従い、契約中の保険会社・代理店に確認してください。

手順4：水災補償は、ハザードマップを見て考える

日本損害保険協会は、すまいの保険（火災保険）には、洪水により家が流された損害などの水災で損害額が一定割合以上に達するもの、 または床上浸水による損害であれば補償の対象としている商品がある、と説明しています。 火災保険における床上浸水は、畳敷や板張など居住の用に供する部分の床（土間、たたきの類を除く）を超える浸水をいう、とされています。 具体的な支払い条件は商品ごとに異なるため、このページでは割合などの数字は書きません。

水災補償を付けるかどうかを考えるときの材料として、国土交通省の「ハザードマップポータルサイト」が使えます。 同サイトの「重ねるハザードマップ」は、洪水・土砂災害・高潮・津波のリスク情報などを地図に重ねて表示し、住所から探すこともできます。 「わがまちハザードマップ」は、市町村が法令に基づき作成・公開したハザードマップにリンクします。 掲載データの内容やリスク情報の解釈は、作成した機関に問い合わせるよう案内されています。

  1. 自宅の住所を入れて、洪水・土砂災害・高潮などのリスクを見る（重ねるハザードマップ）
  2. 市町村のハザードマップも見る（わがまちハザードマップから、自分の市町村のものを開く）
  3. 証券で、いま水災が付いているかを確認する。付いていない場合は、その理由が自宅の立地に合っているかを考える
  4. 判断に迷う点は、保険会社・代理店に聞く。自宅の階数や構造で水災の扱いが変わるかなどは、このページでは確認できていません

これは当サイトの編集上の進め方で、ハザードマップの結果から水災補償の要否を断定するものではありません。 水災補償を付けるかどうかは、見積もりの金額の差とあわせて、自分で決めることです。

手順5：同じ条件で見積もりを取って比べる

書き出した条件を、そのまま見積もりの入力に使います。ポイントは、変える条件と変えない条件を分けることです。

  1. まず「いまと同じ条件」で取る。保険の対象、保険金額、補償範囲、自己負担額、地震保険、期間、特約を手順2の通りに入れます。
  2. 金額は一つの表に並べる。保険料の数字だけでなく、各行に条件（対象、保険金額、水災の有無、自己負担額、地震保険、特約）を併記します。
  3. 条件を変える場合は、1項目ずつ。たとえば水災補償の有無だけ変える、のように動かす点を一つにして、差がどこから来たかを分かるようにします。
  4. 補償の中身を見る。同じ名前の補償でも、支払い条件や範囲が会社によって違うことがあります。保険料の差が、補償の差に見合うかを考えます。

条件が違う見積もりを並べて順位をつけないのが、いちばん外れにくい進め方です。 保険金額を下げて保険料を安く見せていないか、補償が外れていないかを先に確かめます。

手順6：時期と、決めたあとの確認

火災保険の更新で、満期日からどのくらい前に動くのがよいか、満期後にどれだけ猶予があるかは、 確認できた公式資料では示されていません。満期日と手続きの期限は、更新案内と契約中の保険会社・代理店で確認してください。 見積もりの比較は、満期日の十分前に始めると、補償が切れる日をつくらずに済みます。 地震保険を付けている場合は、火災保険と同じ時期に期間が切れるのかも、証券で確認します。

決めたら、最後に次の点を見ます。

  1. 新しい契約の始期日と、いまの契約の満期日がつながっているか
  2. 建物・家財の保険金額と、基準（再調達価額か時価か）が書き出した条件と同じか（変えた場合は意図通りか）
  3. 水災・盗難・水濡れなどの補償と自己負担額が、意図どおりか
  4. 賃貸なら借家人賠償責任・個人賠償責任の特約が、ほかの契約と重複・抜けなく付いているか
  5. 地震保険の有無・金額・期間は、意図どおりか
  6. 支払い方法・保険料の払込期日を確認したか

一括見積もりサイトを使うときの注意

  • 入力した情報の渡り先を確認する。申込前の画面で、情報が複数の保険会社や代理店に渡るのか、どこから連絡が来るのかを読みます。
  • 連絡手段（電話・メール）と、連絡を止める方法も、申込前に確認します。
  • 表示される金額は、入力した条件での見積もりです。手順2の条件を正確に入れないと、更新後の実際の契約とずれます。
  • 並び順や「おすすめ」の表示が何を基準にしているかは、サイトの説明で確認します。

これらはこのサイトの編集上の注意点で、個々のサービスの実際の挙動を確認したものではありません。 使うサービスごとの規約・案内で確かめてください。

住宅の修理を勧める業者には、先に保険会社へ

日本損害保険協会は、住宅修理（リフォーム）に関して「保険金が使える」と言って勧誘する業者とのトラブルが発生していると注意しています。 このような勧誘については、業者と契約する前に、契約している損害保険会社または代理店に相談するよう案内しています。

火災保険の年額を出したら、ほかの固定費と並べて見る

保険料だけを見ても、家計のどこを直すかは決まりません。 家計チェックに入力すると、住居・通信・保険などと並べて確認できます。 登録不要・入力した数字は送信されません。

まとめ

  • 更新案内と保険証券を出し、いまの条件を先に書き出す
  • 火災保険は建物と家財を分けて契約する。借家は家財のみ
  • 保険金額は再調達価額か時価かを確認する。時価を下回ると全額補償されない場合がある
  • 水災・盗難・水濡れなどはタイプ（住宅総合か住宅火災か）と商品で違う。証券で一つずつ確認する
  • 地震・噴火・津波の損害は火災保険では補償されない。地震保険の有無を見る
  • 賃貸は家財、借家人賠償責任、個人賠償責任を確認する
  • 水災補償はハザードマップを見て、見積もりの差とあわせて自分で決める
  • 見積もりは同じ条件で取り、条件を変えるときは1項目ずつ
