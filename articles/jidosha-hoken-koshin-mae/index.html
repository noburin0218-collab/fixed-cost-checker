自動車保険の更新前にやること
保険証券・等級・見積もり条件をそろえる手順

家計の保健室 編集部　/ 公開日 2026年11月5日　/ 最終更新日 2026年11月5日
情報源：日本損害保険協会の公表情報（2026年11月5日確認）／補償・条件・手続きは保険会社ごとに異なります　/　編集方針

更新の案内が届いたら、いきなり見積もりを取る前に、 いまの契約の条件を書き出すところから始めます。 条件がそろっていないと、金額を並べても比べたことになりません。 ここでは、保険証券で確認する項目、同じ条件で比べる方法、時期と注意点を順に整理します。 特定の会社や商品は勧めません。

この記事で分かること

  • 更新案内と保険証券で、先に書き出しておく項目
  • 見積もりを同じ条件にそろえて比べる手順
  • 会社を変えるときの等級の確認と、補償を途切れさせない注意点

保険料の安さだけで決めず、いまの条件を書き出し、同じ条件で比べるのが基本です。補償の空白をつくらないよう、満期日より前に動きます。

この記事で書かないこと

保険料の金額、割引率、等級ごとの保険料の差は書きません。会社・商品・契約条件で変わるためです。 どの会社・どの商品がよいか、順位や推奨も出しません。 等級の数え方や事故有係数の細かい仕組みは、公式に確認できた範囲だけを書き、 それ以外は契約中の保険会社に確認する前提にしています。

手順1：更新案内と保険証券を手元に出す

まず、届いた更新案内（満期のお知らせ）と、保険証券（または契約内容の確認画面）を並べます。 様式は会社ごとに違うため、項目の名前が少し違っても、次の手順2の内容を探せば足ります。

保険証券の一般的な読み方は、保険証券のどこを見る？にまとめています。 この記事では自動車保険に絞って、更新前に特に見る項目を挙げます。

手順2：現在の条件を書き出す

次の項目を、メモや表に写します。意味が分からない項目は、推測で書かず、そのまま写して契約中の保険会社に聞きます。

更新前に書き出す項目
項目どこを見るか確認のしかた
等級・事故有係数適用期間更新案内／保険証券表記をそのまま写す。意味と期間は契約中の保険会社に確認
記名被保険者保険証券主に車を使う人の名前になっているか
運転者の範囲保険証券本人限定・夫婦限定・家族限定など、誰が運転する契約か
運転者の年齢条件保険証券「◯歳未満不担保」など。運転する家族の年齢と合っているか
使用目的・年間走行距離保険証券／申込時の区分いまの使い方と合っているか（通勤・通学が増えた等）
対人・対物賠償保険証券保険金額の設定（無制限か、金額を決めているか）
人身傷害・搭乗者傷害など保険証券自分や同乗者のケガの補償が、どの種類であるか
車両保険保険証券付けているか。付けている場合は補償範囲のタイプと免責（自己負担）の設定
特約・付帯サービス保険証券／約款示談代行、事故時・故障時のサービスなど。名前と中身を分けて書く

等級と事故有係数適用期間について

日本損害保険協会は、自動車保険では保険期間中の事故の有無に応じて契約者の等級が上がったり下がったりし、 それに応じて翌年の契約保険料が増減する「等級別料率制度」が採用されていると説明しています。 同じ協会のページには、このしくみは損害保険会社により多様化しているため、詳細は損害保険会社または代理店に問い合わせるよう書かれています。

そのため、この記事では等級の段階数や、事故があったときに何等級下がるか、事故有係数の適用期間が何年か、といった数字は書きません。 更新案内に載っている等級と事故有係数適用期間の表記をそのまま写し、 見積もりを取るときに同じ値を伝える、という使い方にとどめます。

運転者の範囲と年齢条件は、保険金に直結する

日本損害保険協会は、運転者の年齢を制限して保険料が割引になる契約では、たとえば 「26歳未満不担保特約」で契約している場合に23歳の人が運転して事故を起こしても、 保険金は支払われないので注意が必要だと説明しています。 運転者を家族に限定する割引も同様で、家族以外の人が運転して事故を起こした場合は保険金が支払われないとされています。

更新のタイミングは、運転する人が増えていないか（子どもが免許を取った、同居の家族が増えた等）、 年齢条件の区分が合っているかを見直す機会です。 自分の使い方に合っているかは、約款・保険会社の案内で確認してください。

車両保険は「付けるか」だけでなく「どのタイプか」

同じく日本損害保険協会によると、車両保険には一般的なタイプと、補償範囲を限定して保険料を抑えたタイプがあり、 補償内容は各損害保険会社の商品によって異なります。 詳しくは各損害保険会社または代理店に問い合わせるよう案内されています。 「車両保険あり」とだけ書くと、見積もりで別のタイプが選ばれても気づけません。 タイプ名と、免責（自己負担）の設定を写しておきます。

手順3：同じ条件で見積もりを取って比べる

書き出した条件を、そのまま見積もりの入力に使います。ポイントは、変える条件と変えない条件を分けることです。

  1. まず「いまと同じ条件」で取る。等級・運転者の範囲・年齢条件・使用目的・年間走行距離・車両保険・特約を、手順2の通りに入れます。
  2. 金額は一つの表に並べる。保険料の数字だけでなく、各行に条件（運転者の範囲、年齢条件、車両保険のタイプと免責、特約）を併記します。
  3. 条件を変える場合は、1項目ずつ。たとえば車両保険の免責だけ変える、のように動かす点を一つにして、差がどこから来たかを分かるようにします。
  4. 補償の中身を見る。同じ名前の補償でも、範囲や上限が会社によって違うことがあります。保険料の差が、補償の差に見合うかを考えます。

条件が違う見積もりを並べて順位をつけないのが、いちばん外れにくい進め方です。 金額の差が条件の差から来ていないかを、先に確かめます。

手順4：時期と、補償を途切れさせない注意点

更新の手続きは、満期日までに

日本損害保険協会は、保険料の割増・割引のある任意の自動車保険では、 満期日から一定期間内に契約更改の手続きを行わないと割引を引き継げなくなり、新たな契約と同じ扱いになると注意しています。 「一定期間」が何日かは、確認できた資料に示されていないため、契約中の保険会社に確認してください。 見積もりの比較は、満期日の十分前に始めるのが安全です。 補償が切れる日をつくらないよう、新しい契約の始期日と、いまの契約の満期日をつなげて考えます。

会社を変えるとき：等級はどう確認されるか

日本損害保険協会の「無事故・事故確認制度」は、自動車保険の契約先の損害保険会社等を変更した場合に、 適切な等級の継承確認のため、前年度の契約における保険事故の有無等を損害保険会社等の間で確認する制度と説明されています。 登録・交換されるデータ項目には、適用等級、保険事故の件数、事故年月日、保険期間などが含まれます。 つまり、会社を変えても等級の継承を確認する仕組みはありますが、どの条件で引き継がれるかは、切り替え先の保険会社の取り扱いによるため、見積もりの段階で確認します。

保険期間の途中で切り替えるとき

日本損害保険協会は、保険期間の途中で現在の契約を解約して他の保険会社で新たに契約する場合、 現在の契約の解約日と新しい契約の始期日を同一日にしないと、等級を引き継げない場合があるので注意が必要だとしています。 解約日と始期日は、両方の保険会社・代理店に伝えて、日付をそろえてください。

車を手放す・使わない期間があるとき

日本損害保険協会の「中断特則に関する保険契約確認制度」は、契約の車の廃車・譲渡・リース業者への返還、 車検切れ、または契約者の海外渡航などで自動車保険の契約を一時的に中断した場合に、 中断後の新しい契約へ中断前の等級を適用するとき、中断前の契約内容を確認するための制度と説明されています。 中断できる期間や適用の条件は、このページでは確認できません。 該当する場合は、解約する前に契約中の保険会社へ確認してください。

一括見積もりサイトを使うときの注意

  • 入力した情報の渡り先を確認する。申込前の画面で、情報が複数の保険会社や代理店に渡るのか、どこから連絡が来るのかを読みます。
  • 連絡手段（電話・メール）と、連絡を止める方法も、申込前に確認します。
  • 表示される金額は、入力した条件での見積もりです。手順2の条件を正確に入れないと、更新後の実際の契約とずれます。
  • 並び順や「おすすめ」の表示が何を基準にしているかは、サイトの説明で確認します。

これらはこのサイトの編集上の注意点で、個々のサービスの実際の挙動を確認したものではありません。 使うサービスごとの規約・案内で確かめてください。

手順5：決めたら、最後に確認すること

  1. 新しい契約（または更新）の始期日と、いまの契約の満期日・解約日がつながっているか
  2. 運転する人全員が、運転者の範囲と年齢条件に入っているか
  3. 車両保険のタイプ・免責、特約が、書き出した条件と同じか（変えた場合は意図通りか）
  4. 等級・事故有係数適用期間の扱いを、切り替え先に確認したか
  5. 支払い方法・保険料の払込期日を確認したか

まとめ

  • 更新案内と保険証券を出し、いまの条件を先に書き出す
  • 等級・事故有係数適用期間は表記をそのまま写し、意味は契約中の保険会社に確認する
  • 運転者の範囲・年齢条件は保険金が支払われるかどうかに直結する
  • 車両保険は、付けるかどうかに加えてタイプと免責を見る
  • 見積もりは同じ条件で取り、条件を変えるときは1項目ずつ
  • 満期日から一定期間を過ぎると割引を引き継げなくなる。満期日の十分前に動く
  • 会社を変えるときは、等級の継承確認の仕組みがある。解約日と始期日をそろえる
